# Bob session artifacts

The IBM Bob hackathon guide requires real task-session evidence for the work used in the submission.

For every relevant task and every team member:

1. Open the task history for the correct workspace. Use **All** if the task spans workspaces.
2. Open the task header and capture the task-session consumption summary.
3. Export the task history as a Markdown file.
4. Place the screenshot and exported Markdown file in this directory.

Do not add credentials, API keys, personal information, client data, or confidential material. Do not create placeholder reports; these artifacts must reflect actual IBM Bob usage.
