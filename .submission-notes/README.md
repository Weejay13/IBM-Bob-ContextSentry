# ContextSentry submission assets

## Upload these

- Cover image: `contextsentry-cover.png`
- Slide presentation: `contextsentry-slides.pdf`
- Video demonstration: record using `VIDEO_SCRIPT.txt` and export as `contextsentry-demo.mp4`

## Public links

- Demo: https://ibm-bob-contextsentry.onrender.com
- Repository: https://github.com/Weejay13/IBM-Bob-ContextSentry

## Recording rules

- Do not show `.env`, API keys, credentials, or personal data.
- Never run `npm install` or the poisoned fixture's `postinstall` script.
- Open the Render URL before recording because the free service can sleep.
- The video should show detection, blocked actions, safe remediation, the audit chain, and the IBM Bob workflow.
