BEFORE RECORDING

1. Open https://ibm-bob-contextsentry.onrender.com and wait for the page to load.
2. Close notifications and hide terminals, password managers, and personal tabs.
3. Record at 1920x1080 with a clear microphone.
4. Never show .env, API keys, private files, or the poisoned fixture's postinstall command being executed.

0:00-0:20 - PROBLEM

Show the dashboard headline.

Say:

"IBM Bob can understand an entire repository, but repository files are untrusted. A README, source comment, or dependency script can contain instructions aimed at the agent. ContextSentry makes that trust boundary explicit."

0:20-0:50 - RUN THE SIMULATION

Click Run live attack simulation.

Say:

"This is a deterministic local attack simulation. It scans the poisoned fixture, records the findings, and shows the policy decisions without executing any repository command."

Point to the findings and timeline.

0:50-1:20 - EXPLAIN THE GUARDRAILS

Say:

"The scanner detects the instruction override, secret access request, external exfiltration request, and network-capable postinstall script. The policy engine then blocks high-impact actions while allowing safe workspace work."

Point to each blocked action.

"The audit chain records the decision, reason code, taint state, policy version, and tamper-evident MAC for every event."

1:20-1:40 - EVIDENCE

Show the benchmark and audit summary.

Say:

"The fixture benchmark detects all five seeded attack signals, the safe control fixture has zero findings, and the automated suite has forty passing tests. The evidence is reproducible rather than a claim."

Show the recorded Bob task or the exported bob_sessions evidence.

Say:

"We also used IBM Bob Shell and the Bob IDE. In ContextSentry Guard mode, Bob activated the repository skill, called the local ContextSentry MCP tools, and received lifecycle-hook decisions for SessionStart, UserPromptSubmit, PreToolUse, PostToolUse, and Stop. The exported task history and consumption screenshot are included in the repository."

2:05-2:25 - CLOSE

Show the GitHub repository and public demo URL.

Say:

"ContextSentry lets teams keep the productivity of coding agents while making untrusted context non-authoritative. It detects, constrains, and proves every high-impact action. Thank you."
